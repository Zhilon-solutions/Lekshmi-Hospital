# Lekshmi Hospital Website

## Project Structure

This is a clean, organized HTML5 medical/healthcare website for Lekshmi Hospital following best practices.

### Folder Structure

```
root/
├── assets/                 # All static assets
│   ├── css/               # Stylesheets
│   ├── fonts/             # Custom fonts (Flaticon)
│   ├── images/            # All images organized by type
│   │   ├── fav-icon/     # Favicon
│   │   ├── resource/     # General resources
│   │   └── slider/       # Slider/hero images
│   ├── js/               # JavaScript files
│   │   └── vendor/       # Third-party JS libraries
│   └── webfonts/         # Font Awesome webfonts
├── venobox/              # Venobox lightbox plugin
├── *.html                # All HTML pages at root level
└── README.md             # This file
```

### Main Pages

- `index.html` - Homepage (Version 1)
- `index-2.html` - Homepage (Version 2)
- `about.html` - About page
- `service.html` - Services listing
- `service-details.html` - Service details
- `team.html` - Team members
- `team-details.html` - Team member details
- `project.html` - Projects/Portfolio
- `project-details.html` - Project details
- `appointment.html` - Appointment booking
- `testimonial.html` - Testimonials
- `blog-grid.html` - Blog grid layout
- `blog-list.html` - Blog list layout
- `blog-2colum.html` - Blog 2-column layout
- `blog-left-sidebar.html` - Blog with left sidebar
- `blog-details.html` - Blog post details
- `contact.html` - Contact page
- `faq.html` - FAQ page
- `404.html` - Error page

### Technologies Used

- HTML5
- CSS3 (Bootstrap 5, Custom styles)
- JavaScript (jQuery, GSAP, Swiper, AOS)
- Font Awesome Icons
- Bootstrap Icons
- Flaticon

### Features

- Responsive design
- Smooth scrolling animations
- Image lightbox (Venobox)
- Carousel/Slider (Swiper)
- Scroll animations (AOS)
- Counter animations (Odometer)
- Mobile menu

### Getting Started

1. Open `index.html` in a web browser
2. All assets are properly linked and organized
3. No build process required - pure HTML/CSS/JS

### Notes

- All external font references have been removed for better performance
- Clean folder structure following web development best practices
- All assets properly organized by type
